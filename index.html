The difference

Autonomy is a dial, not a switch.

Most incident agents give you one binary gate: approve, or the agent does nothing. Sentinel runs a tier system. You grant more authority to the patterns it has already proven, and keep a human on the ones it has not.

TIER 0observe
Reads telemetry, forms a hypothesis, opens nothing. The floor for any service Sentinel has just met.
read-only
TIER 1propose
Diagnoses the fault and drafts the exact change, then hands it to an engineer to run.
human runs
TIER 2approve
Prepares the mitigation and executes it the moment an on-call engineer confirms. One tap, not a shell session.
awaiting approval
TIER 3authority
Acts on its own for a fix it has already run safely, on a service you have cleared. Escalates anything outside the pattern.
autonomous
